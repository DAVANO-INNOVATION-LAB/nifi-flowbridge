# Contributing

Run the Python suite with `python -m unittest discover -s tests -v`. The core application uses only the Python standard library. Keep uploaded definitions as data; never execute, evaluate or fetch their contents.

Start a mapping proposal with a secret-free synthetic flow and the exact source/target runtime versions. Describe observable semantics, unsupported settings and loss risks. Add import/export fixtures, round-trip coverage, negative tests and native runtime evidence. A parser that accepts its own output is not sufficient evidence of target compatibility.

Keep scope focused. Do not copy code from another project without checking its license, provenance and attribution requirements. Submit changes under Apache-2.0. Maintainers review generated artifacts and test results before merging.

Public issue templates cover reproducible defects and mapping requests. See docs/support.md for triage. Do not post private production data, tokens, account details or credentials.
